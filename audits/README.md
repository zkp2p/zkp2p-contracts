# Security Audits

Structured security audit reports for ZKP2P V2 contracts, generated by the `security-auditor` agent using Trail of Bits security skills.

## Directory Structure

```
audits/
  full/              # Full audit reports (10-step workflow)
  differential/      # PR/branch differential reviews
  templates/         # Report templates
  _scratch/          # Working space (gitignored)
```

## Prerequisites

The security-auditor agent requires [Trail of Bits Claude Code plugins](https://github.com/trailofbits/claude-code-plugins) installed globally:

```bash
claude plugins install @trailofbits/building-secure-contracts
claude plugins install @trailofbits/audit-context-building
claude plugins install @trailofbits/static-analysis
claude plugins install @trailofbits/variant-analysis
claude plugins install @trailofbits/differential-review
claude plugins install @trailofbits/entry-point-analyzer
claude plugins install @trailofbits/sharp-edges
claude plugins install @trailofbits/property-based-testing
claude plugins install @trailofbits/semgrep-rule-creator
```

## Running Audits

```
/audit              # Full 10-step security audit
/audit full         # Same as above
/audit diff         # Differential review (current branch vs main)
/audit pr <number>  # Differential review of a specific PR
/audit check <skill># Run a single security skill (e.g., semgrep, maturity)
/audit maturity     # Quick code maturity assessment
/audit entries      # Entry point mapping
```

## Report Naming

- Full audits: `full/YYYY-MM-DD-full-audit.md`
- Differential: `differential/YYYY-MM-DD-pr-<number>.md` or `differential/YYYY-MM-DD-<branch>.md`

## Commit Convention

Audit reports are committed with: `audit: <type> security audit at <short-sha>`
